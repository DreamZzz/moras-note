# MORAS 周边项目与待确认事项

## lark-agent

`lark-agent` 是运行在个人电脑上的飞书会话与 Codex 桥接服务，负责：

- 接收飞书消息并映射到 Codex Thread/Turn；
- 保存 SQLite 会话、附件、回复、审批和恢复状态；
- 将高风险外部写操作转成飞书审批与执行回执；
- 通过 Host Dynamic Tools 接入 PR Review、Issue、Todo 和部署查询能力；
- 以 Outbox 保证消息和媒体投递的持久性与幂等。

它默认绑定 `127.0.0.1`。`shadow` 模式只记录消息；确认监听、授权对象和审批接收人无误后才适合切换到 `active`。

当前会话中已经使用“赵强的飞书 CLI”完成授权和消息验证。现阶段只将其作为交互与查询入口，不接入 CI/CD。

## moras-forge

当前本机没有发现 `moras-forge` 仓库。根据 `lark-agent` 的集成契约，Forge 更接近本地 Host/控制台：

- 向 `lark-agent` 注册 PR Review、Issue Triage、Todo 和部署检查等能力；
- 提供消息页面和 Listener Switch；
- 当配置 `LARK_AGENT_URL=http://127.0.0.1:4780` 时，由 Forge 代理独立运行时，而不是启动旧 Listener；
- 外部写操作仍由 `lark-agent` 绑定到具体飞书消息和审批上下文。

若要形成独立的 Forge 架构笔记，需要重新定位或克隆仓库后核对代码。
