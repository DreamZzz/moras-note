# MORAS 自有模型与 AI 长期技术战略

> [!summary] 第一版核心判断
> 模型权重本身未必构成护城河。MORAS 的长期优势应来自专有业务数据、可验证的业务评测、持续反馈学习、供应商可替换架构，以及把行业认知转化为模型、策略和工作流资产的能力。

## 董事会结论

- **为什么做**：不能把佣金链路控制权交给单一模型厂商。厂商可能涨价、限流、改变内容与数据政策、进入相邻业务，或受区域及资本阵营限制。
- **现在做什么**：不从零搭平台。以已有 `moras-brain`、`moras-agent`、Finder/Product、Video/Media、Schema/Composer 为骨架，先贯通全链路 ID、模型与成本观测、业务归因、评测和供应商切换，再补真正缺失的能力。
- **暂时不做什么**：不训练通用基础模型；不因“自主可控”提前私有化前沿视频模型；不建设脱离业务闭环的大而全 Agent 平台。
- **何时升级**：某一任务达到稳定规模，自有评测与在线效果持平，三年 TCO 显著占优，12–18 个月可回收，并有持续反馈和回退能力时，再升级到微调、蒸馏、私有化或专项自研。

## CTO 战略原则

1. 模型可采购，控制面必须自有。
2. 业务结果是“效果持平”的最终定义。
3. 依赖按可逆性管理：可接受依赖用合同与 SLA 管理，关键路径必须可替代。
4. 自建按任务经济性决策，不使用统一盈亏平衡点。
5. 运营经验、Agent 轨迹和线上结果必须资产化，不能只存在于员工、Prompt 或供应商模型内部。

## 能力主权分层

### 必须自有

- 商品—达人—内容—交易闭环数据、统一 ID、特征与标签。
- 业务黄金集、在线实验、因果归因和反馈学习。
- 选品、创意、达人匹配与合规策略。
- 模型网关、路由、成本质量观测、Prompt/Agent 版本、审计与退出演练。

### 必须可替代

- Seedance 等视频生成能力。
- DeepSeek、Gemini 等推理和多模态理解能力。
- Agent 运行时、向量/检索、推理云与 GPU 供应。

关键路径需要第二供应商、开源备份或功能降级；输入输出、数据和工作流保持可迁移。

### 可长期外购

- 前沿通用预训练和基础算力。
- 通用内容安全、非差异化 SaaS 与标注产能。

## 三条能力链

### 选品

本质是推荐排序、趋势预测、供需匹配和经营决策。优先自建商品/达人/内容/交易特征、候选召回、排序与转化/佣金预测。专项排序模型可能是最早形成自建优势的模型。

### 商品理解

继续采购多模态底座，自建商品与达人语义层、卖点/受众/场景/风险标签、知识库、评测集和解析流水线。只有稳定类目缺口影响转化且有足够样本时才微调或蒸馏。

### 视频生成

短期继续使用外部前沿视频 API，并接入第二供应商与降级路径。自建重点是创意策略、达人风格表示、脚本/镜头/素材编排、Agent 流程、生成评测和后处理，而不是视频基础模型。

## 代码调研后的现状判断

第一版路线图把 MORAS 过多地当成绿地项目。`moras代码仓库review` 的复核表明，系统骨架已经存在：

- `moras-brain` 已负责模型选择、上下文、工具调用与 Multi-Agent 编排。
- `moras-agent` 已是运行档案库、配置控制面和任务状态中心，覆盖配置发布与版本、会话/记忆、Task/Event/Checkpoint/Heartbeat/Recovery、Workflow/Pipeline，以及 Trace、QA、人工 Review 和 Usage。
- `moras-finder` 已完成商品采集、原始数据留存、趋势/质量/内容评分，并同步业务库与 Meilisearch；`moras-product` 承担检索与推荐接口。
- `moras-video` 与 `moras-media` 已承担异步生成、TTS/ASR、FFmpeg Job 和媒体后处理。
- `moras-schema` 与 `moras-composer` 已承载 DDL/Migration、Compose、Helm、Argo CD、Secret、监控和 CI/CD。

已验证的工程事实包括：`moras-agent` 的 Go build 和标准测试通过；本地 MySQL 中 `ai_agents` 有 49 张表、`ai_journal` 有 4 张表；健康检查、内部鉴权、Metrics、DAO/LUI 持久化路径可用。

因此，当前主要缺口不是“有没有 Agent 平台”，而是：跨服务统一身份和观测、商业结果归因、生产级 E2E、评测与反馈闭环、供应商切换演练。尚未验证的事项不能直接解释为能力不存在。

## 目标架构

1. **业务与策略层**：选品、达人匹配、创意、合规与探索利用策略。
2. **学习与评测层**：黄金集、离线评测、在线实验、奖励信号、归因与训练。
3. **数据与特征层**：统一 ID、特征、标签、知识与血缘。
4. **编排与控制层**：模型网关、抽象层、路由、缓存、批处理、版本、回退与审计。
5. **模型供应层**：闭源 API、开源托管、私有小模型、专项模型和视频供应商，可插拔选择。

## TCO 决策框架

**API 三年 TCO** = 调用/生成费用 + 峰值溢价 + 失败重试 + 数据传输/存储 + 人审返工 + 供应商管理 + 价格与汇率风险。

**自建三年 TCO** = 数据建设 + 训练/微调 + GPU 与峰谷闲置 + 工程平台 + 模型维护/重训 + 评测/安全/合规 + 核心人才 + 迁移与机会成本。

**盈亏平衡月量** = 年固定自建成本 ÷ 12 ÷（API 单次成功成本 − 自建单次成功可变成本）。

“成功”必须是完成业务任务并通过质量和合规门槛；失败、重试、人工接管及未发布内容全部计入成本。

降本顺序：API 基线 → 路由与预算控制 → 缓存/批处理/上下文压缩 → 小模型承担稳定子任务 → 蒸馏/微调 → 开源私有化 → 专项模型自研。

## 供应商自主性

- Seedance/视频链路：双供应商与轻量降级，目标 24 小时恢复基础生成、7 天恢复主要质量档位。
- Gemini/多模态与推理：统一 JSON Schema 和工具协议，影子运行备选模型，目标 4 小时切换核心文本链路。
- DeepSeek/推理：API 与开源权重双基线，关键 Prompt 回归集，目标 4 小时切换、30 天内完成私有化应急评估。
- 每季度技术回放，每年至少一次真实退出演练；记录 RTO、RPO、质量差距、成本、迁移工时和合规影响。

## 数据与认知飞轮

采集完整业务与 Agent 轨迹 → 归因各环节贡献 → 转成标签、偏好、失败类型、奖励、知识、特征和训练集 → 更新排序模型、策略、评测器、路由和 Agent → 通过 A/B 或灰度验证佣金/千次曝光及贡献毛利 → 增益不可复现则回退。

## 0–36 个月路线

- **0–3 个月｜贯通现有骨架并建立事实基线**：以 `moras-agent` 为运行与审计账本，在 Brain→Agent→Product/Finder→Video/Media 的真实链路统一 `correlation_id`、模型/供应商/版本、成本、时延、失败和产物字段；通过 Schema/Composer 落地。补齐 Docker/FFmpeg、`ai_video`、测试凭据和 staging 黄金路径。里程碑是一条请求可从 API/Edge 追踪到 Brain↔Agent、商品候选、视频/媒体产物及发布后结果，并可用现有 Trace/QA/Review/Usage 回放。
- **3–12 个月｜形成评测与增长闭环**：连接 Agent 的 Trace、QA、人工 Review、Usage 与发布/曝光/成交/佣金；在 Finder/Product 候选集上做排序实验；在 Brain/Video 的真实模型入口做多供应商路由、影子流量和回退；建立商品/达人语义层。里程碑是至少一项实验持续改善佣金/千次曝光或单位成功成本，并完成一次全链路恢复演练。
- **12–24 个月｜选择性模型化**：只对已验证的高频窄任务做排序/转化、商品理解、生成评测小模型或蒸馏；把线上结果转成版本化特征、标签、技能和知识候选；按规模评估私有推理与视频风格适配。里程碑是专项模型相对最佳 API 基线在质量×成本上连续领先，且能通过 Agent/Schema/Composer 审计与回滚。
- **24–36 个月｜形成能力主权与规模经济**：关键链路具备双供应商或开源备份，高频稳定任务迁至自有模型，形成跨市场学习和自动策略更新；完成年度供应商退出、数据恢复和灾备演练。

停止条件：数据无法闭环、在线收益不能复现、复用不足、三年 TCO 不占优或业务毛利无法覆盖团队和算力时，不扩大训练投入。

## 必须长期保有的组织能力

- 核心算法与数据团队：推荐、预测、语义表示、归因、训练集和评测器。
- 平台能力先落在现有服务 owner 中：Brain 承担模型入口、路由与编排；Agent 承担状态、版本、Trace/QA/Review/Usage；Schema/Composer 承担数据契约、部署、监控与回滚。只有跨两条链路复用且现有边界无法承载时，才拆出独立 AI 平台团队。
- 应用/Agent 能力继续围绕 Brain 与 Agent 演进：商品理解、创意策略、工作流、人工协同与业务接入。
- 安全/法务/采购：数据权利、素材和达人授权、内容合规、供应商竞争风险和退出条款。

## 待验证事实

- 当前 GMV、佣金率、贡献毛利和目标增长。
- 商品与达人覆盖、日候选量、日生成量。
- Seedance、DeepSeek、Gemini 在各环节的调用量、成本、时延、失败率和限流。
- 推荐→采用→生成→发布→曝光→点击→成交的漏斗。
- 标签、负样本、人审修改/拒绝和违规数据是否完整。
- TikTok 数据获取、归因、跨境、版权、肖像和生成标识边界。
- 团队结构、现有平台能力、GPU 和预算约束。
