## 启动 moras-agent

```bash
cd /Users/zhao/Documents/Workspace/.worktrees/moras-agent-version-endpoint
set -a
source .env
set +a
go run .
```

本地端口配置为 `16092`。另开终端验证：

```bash
curl http://127.0.0.1:16092/health
```

预期：

```json
{"service":"moras-agent","status":"ok"}
```

内部接口需要 `.env` 中的内部访问 Key。不要把 Key 直接写入 Shell 历史或文档。

## 构建与测试

export GOPROXY=https://goproxy.cn,direct
